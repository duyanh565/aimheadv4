01

Neon control panel

API key chỉ được dùng trong phiên này, không lưu vào Railway.

API key là mã riêng của NextDNS, không phải mật khẩu. Bấm “TẢI PROFILE” để lấy các cấu hình trong tài khoản.

02

Miền chặn

Mỗi miền một dòng hoặc phân cách bằng dấu phẩy.

03

Miền cho phép

Danh sách này được thêm vào allowlist.

04

File mobileconfig

Không tải file thì sẽ dùng mẫu ANTIBANDA mặc định.

ID sẽ được thay ở phần sau .antiban. và trong URL https://dns.nextdns.io/ID.
